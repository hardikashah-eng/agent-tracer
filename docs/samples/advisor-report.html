Move bitbucket calls to code mode or a CLI

highefficiency third_party 15/20 sessions · 15 occurrences
~97,219 tokens · ~15,396 ms · ~4.85 model turns
est. per session

Each page or item costs a full model turn; a script can paginate and fan out in one step and return only the aggregate.

Third-party server: only levers you control are listed (harness, gateway, facade) plus a vendor request.

Harness
  • Expose bitbucket through code mode: generate typed stubs from tools/list (MCPorter emit-ts, code2mcp) and let the model write one script that loops in a sandbox.
  • For bulk reads, call the official CLI/REST API through the egress gateway with delegated credentials.
Gateway
  • Publish a virtual tool on the gateway that paginates server-side and returns the aggregate.
Vendor request
  • Ask the vendor for a batch/aggregate endpoint or larger page sizes, citing call counts.
